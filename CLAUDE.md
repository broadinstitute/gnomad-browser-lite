# Claude Code Instructions

## Starting Servers

```bash
pnpm start              # Both backend + frontend (with hot reload)
./scripts/start-backend.sh   # Backend only
./scripts/start-frontend.sh  # Frontend only
```

## Port Configuration

Each worktree has unique ports based on a hash of its name, allowing multiple worktrees to run simultaneously:

- **Main project**: 3000 (backend), 5173 (frontend)
- **Worktrees**: Unique ports stored in `.env`

Always check `.env` for the current worktree's ports before starting or debugging:
```bash
cat .env
```

When killing servers in a worktree, use the ports from `.env`, not hardcoded defaults.

## Restarting

- **Frontend**: Vite HMR auto-reloads on file changes
- **Backend**: cargo-watch auto-rebuilds on file changes (if installed)
- **Full restart**: `pnpm stop && pnpm start`

```bash
pnpm stop   # Kills servers using ports from .env
pnpm start  # Restart both
```

## Setup

```bash
./scripts/setup.sh                            # Main project
./scripts/setup.sh --worktree-name X          # Existing worktree
./scripts/setup.sh --create-worktree ../X --from-main  # Fast: copy data/build from main
./scripts/setup.sh --skip-data                # Skip data export
```

## Viewing in Browser

Use the Chrome MCP to view the frontend at the port from `.env`:

```bash
# Check ports first
cat .env  # e.g., VITE_PORT=5955
```

Then use `mcp__claude-in-chrome__navigate` to open `http://localhost:$VITE_PORT`.

For verification, compare results with the official gnomAD browser at https://gnomad.broadinstitute.org/

## Key Files

- `.env` - Port configuration (gitignored, generated by setup)
- `data/test_intervals.json` - Genomic regions to export
- `backend/src/main.rs` - API server
- `frontend/src/` - React app
