The Canadian Genomic Data Commons provides access to quality-controlled genomic
variant data generated from Canadian genomic cohorts using the gnomAD QC pipeline.

### Dataset

- **10,487 genomes** from the HostSeq cohort
- **9 ancestry groups** inferred by PCA and ancestry inference
- Processed with **gnomAD QC v3** pipeline at BC Cancer Genome Sciences Centre

### Example Genes

- [PCSK9](/gene/PCSK9) — Proprotein convertase subtilisin/kexin type 9
- [BRCA1](/gene/BRCA1) — Breast cancer type 1 susceptibility protein

### About

Created as part of the **Pan-Canadian Genome Library (PCGL)** and the
**Canadian Genomic Data Commons (CGDC)**.
